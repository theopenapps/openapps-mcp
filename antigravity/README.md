# OpenApps for Antigravity

OpenApps answers questions about the app stores inside AI assistants: what is listed, ranked, featured and launched in the ChatGPT, Claude, Cursor, Grok Bot, Perplexity and Muse stores, and which tools their apps' MCP servers expose. Answers use OpenApps data, give the date it refers to and link to each app's page on theopenapps.com.

The plugin adds one remote MCP server, `https://theopenapps.com/mcp/directory` (Streamable HTTP). It works without an account or key; signing in to an OpenApps account (OAuth) is optional and opens other countries and more history.

Try:
- Use OpenApps to show the top Productivity apps in the ChatGPT app store
- Use OpenApps to list the Claude connectors launched this week
- Use OpenApps to show which tools an app's MCP server exposes
